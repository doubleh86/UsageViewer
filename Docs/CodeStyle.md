# C# 코드 스타일

UsageViewer Windows 트레이 앱에 다음 C# 규약을 적용한다.

- 4칸 들여쓰기, Allman 중괄호, PascalCase 타입·메서드·속성, `_camelCase` private 필드를 사용한다.
- 언어 버전은 프로젝트 설정을 따른다. 축약보다 읽기 쉬운 명시적인 코드를 우선한다.
- 한 줄은 120열을 권장한다. 짧고 명확한 호출은 유지한다.
- 여러 줄 호출·선언은 첫 인자를 메서드명과 같은 줄에 두고, 후속 인자를 첫 인자 시작 열에 맞춘다.
- `if`, `else`, 반복문에는 한 줄이어도 중괄호를 쓴다. boolean 조건은 `== true` / `== false`로 명시한다.
- 검증, 주요 처리, 결과 구성 사이에는 빈 줄 하나를 둔다. 줄 끝 공백은 남기지 않는다.
- 방어 조건은 먼저 반환하거나 예외를 던진다. 오류를 빈 모델이나 기본값으로 숨기지 않는다.
- 비동기 호출 결과를 다른 호출의 인자 안에서 직접 `await`하지 않고 지역 변수로 분리한다.
- UI 스레드를 블로킹하지 않는다. 외부 프로세스 조회에는 timeout과 cancellation, 확실한 종료 처리를 둔다.
- 시간은 `DateTimeOffset`으로 보관하고 표시할 때 시스템 로컬 시간으로 변환한다.
- 상태를 가진 클래스의 보조 로직은 private 인스턴스 메서드로 둔다. 재사용 순수 함수만 목적이 분명한 Helper에 둔다.
- 보조 모델은 중첩 타입보다 namespace 아래 최상위 타입으로 둔다.
- 변경으로 새로 미사용이 된 코드는 정리하되 기존 무관한 코드는 건드리지 않는다.
- 외부 패키지 없이 가능한 기능은 .NET/Windows 기본 API를 우선 사용한다.
- 실제 동작·경계 조건을 확인하는 검증을 우선하며 구현을 복제한 테스트나 일회성 테스트 프로젝트를 추가하지 않는다.
