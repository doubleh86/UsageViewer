# 로컬 저장소 작업

- 작업 경로는 체크아웃한 저장소 루트이며, 기본 브랜치는 `main`이다.
- 2026-10-30 사용자 푸시 요청으로 GitHub `doubleh86/UsageViewer`를 원격 저장소로 사용한다.
- 요청된 변경만 커밋·push한다. 저장소 공개 전환이나 다른 원격 연결은 별도 요청이 있을 때만 수행한다.
- 작업 시작 시 현재 브랜치, staged/unstaged/untracked 변경을 확인한다.
- 다른 작업자의 변경은 reset, stash, 삭제하거나 임의 커밋하지 않는다.
- 기능 추가 전 `Docs/Plan/`에 목표·근거·범위·예상 파일·검증 방법·상태를 기록한다.
- 승인된 범위의 구현과 직접 영향받는 보정은 재확인 없이 진행한다. 범위가 바뀌면 계획부터 갱신한다.
- 자기 diff, `git diff --check`, 최소 프로젝트 빌드와 필요한 로컬 동작을 확인한다.
- 빌드 성공, 실제 사용량 조회, UI 동작·화면 확인은 구분해서 기록한다.
- Git 초기화는 자동 커밋 승인이 아니다. 사용자가 요청한 경우 자기 변경만 커밋한다.
- 자동 시작 등록, 설치·배포, 외부 공개는 별도 요청 범위로 다룬다.

## 공개 전 개인정보 확인

- 문서와 예제에 개인 절대 경로·실명·회사 정보·비공개 프로젝트 정보를 넣지 않는다.
- 커밋 작성자·커미터에는 공개용 닉네임과 GitHub noreply 이메일을 사용한다.
- 현재 파일뿐 아니라 공개할 브랜치·태그의 과거 커밋도 확인한다.
- 개인정보를 제거한 과거 이력을 반영할 때는 원격 HEAD를 재확인하고 명시적인 lease로 보호한다.
- 로컬 작업 복구용 참조나 reflog는 공개 대상에 포함하지 않는다. `push --mirror`는 사용하지 않는다.
