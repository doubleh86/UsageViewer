# 커밋 메시지 규칙

`[파트, 작성자] - 작업 내용` 형식을 사용한다.

- 작성자는 Git에 설정된 공개용 닉네임을 사용하고 AI·Codex 같은 도구명을 작성자로 쓰지 않는다.
- 작성자의 실제 파트를 사용한다. 예: `[앱, contributor] - 사용량 표시 개선`.
- 작업 내용은 변경 결과를 간결하게 적고, 관계없는 변경은 한 커밋에 섞지 않는다.
- 커밋 작성자·커미터의 이름과 이메일, 메시지에는 실명·회사 이메일·PC 이름·OS 사용자명을 넣지 않는다.
- 이메일은 GitHub의 noreply 주소를 사용한다. 공개용 Git 신원은 저장소 로컬 설정에만 적용한다.
- 사용자 요청 없이 신원 정보를 새로 설정하거나 커밋하지 않는다.
- 원격 자동 push 규칙은 적용하지 않는다.
