# 공개 전 검토

검토일: 2026-11-02. 대상: `main`의 기존 4개 커밋과 잔여량 경고·트레이 연결 문구 변경,
`UsageViewer-v0.1.0-win-x64-menu-text-20261102-122755.zip`.

## 결과

현재 점검 범위에서 공개를 막는 비밀정보·개인정보 노출은 발견하지 못했다.
이는 파일명 점검, 비밀정보·개인 경로·내부 주소 패턴 검사 및 관련 코드 검토 결과이며,
완전한 보안 감사나 서비스 약관 적합성 보증은 아니다. 저장소 공개 전환은 수행하지 않았다.

- 기존 4개 커밋의 고유 파일 내용 48개와 현재 소스·문서를 검사했다.
  키·토큰·개인 절대 경로·회사 이메일·내부 주소에 해당하는 노출을 발견하지 못했다.
  검사에서 잡힌 `.gitignore`의 `AGENTS.local.md`는 일반적인 개인 지침 제외 규칙이었다.
- 커밋 작성자·커미터는 공개용 닉네임과 GitHub noreply 이메일이었다.
- 원격 브랜치는 `main` 하나, 태그·GitHub 릴리즈·Actions 실행·보관 산출물은 없었다.
  이 결과는 검토 당시 상태이며 향후 업로드 항목에는 별도 점검이 필요하다.
- 최신 ZIP에는 로그인 프로필·쿠키·인증 파일·사용량 캐시·개인 설정·디버그 기호가 없었다.
  WebView2 `LICENSE.txt`·`NOTICE.txt`가 포함되어 있다.
- Codex는 자식 App Server를 통해 계정·한도를 조회하며 앱 코드가 인증 파일을 직접 읽지 않는다.
  Claude는 별도 WebView2 프로필에서 사용자가 로그인하고 실제 사용량 응답만 정규화한다.
  알림 기록에는 구간 해시·경고 단계·시각만 저장한다.

## 공개 시 정리할 사항

- 2026-11-02 사용자 요청으로 프로젝트에 [MIT License](../LICENSE)를 적용했다.
  저작권 표기는 `Copyright (c) 2026 doubleh86`이며 빌드·배포 출력에 프로젝트 LICENSE를 포함한다.
  WebView2 등 외부 구성 요소의 라이선스·고지 파일도 별도로 유지한다.
- Claude 웹 사용량은 공개 API 계약이 아닌 페이지 응답에 의존한다. 서비스 변경에 따라 중단될 수 있다.
  공식 OpenAI·Anthropic 제품이나 공식 지원 연동으로 소개하지 않는다.
- 배포에는 빌드한 패키지만 사용한다. `%LOCALAPPDATA%/UsageViewer`에는 로그인 세션과
  개인 사용량 캐시가 있으므로 해당 폴더를 첨부하거나 저장소에 복사하지 않는다.
- 향후 ZIP에도 WebView2 고지 파일을 유지하고, 개인 프로필·설정·로그·인증 데이터 제외를 재확인한다.
- Release 빌드 및 기존 경고 정책·화면 검증은 통과했다. 이번 공개 검토에서는 실제 계정 조회,
  시험 사이렌 재생, 사용자 앱 조작을 수행하지 않았다.
