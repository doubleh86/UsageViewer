# 잔여량 레드 얼럿

## 요청과 동작

잔여 사용량이 적을 때 붉은 경고와 짧은 사이렌을 제공하되 계속 반복하지 않는다.

- Codex·Claude의 유효한 모든 한도 구간을 확인한다. 잔여 10% 이하는 주의, 5% 이하는 긴급이다.
- 낮은 잔여량은 상단 셀과 상세 한도에 붉은 강조·텍스트로 표시한다. 깜박임과 강제 상세 열기는 없다.
- 새 주의/긴급 단계는 포커스를 빼앗지 않는 작은 알림을 약 6초 표시한다.
- 사이렌은 긴급 단계에서만 약 1.2초, 완만한 두 번의 음높이 변화로 한 번 재생한다.
  외부 음원·패키지·네트워크를 추가하지 않고 PCM WAV를 메모리에서 합성한다.
- 제공자·한도·초기화 구간·경고 단계별로 한 번만 알린다. 재실행해도 중복 알림을 방지한다.
  여러 한도가 동시에 낮으면 묶고, 서로 다른 제공자의 연속 알림은 1분 간격으로 제한한다.
- 처음 낮은 값으로 시작하면 해당 단계를 한 번 알린다. 주의에서 긴급으로 내려가면 긴급을 추가로 한 번 알린다.
  15% 이상으로 회복하거나 새로운 초기화 구간이 시작하면 다시 경고할 수 있다.
- 미수신·조회 실패·15분 이상 오래된 수신·만료 구간·잘못된 값은 경고 판정에서 제외한다.
- 우클릭 메뉴의 ‘잔여량 경고음’ 체크로 사이렌을 끄며 설정을 저장한다. 끄면 재생 중인 소리도 중단한다.
- 전체화면 작업 중에는 팝업 알림과 사이렌을 억제하고, 표시 가능한 상태의 잔여량 강조는 유지한다.
- 경고 기록은 사용량이나 계정 ID 대신 구간의 해시 키·단계·시각만 로컬 저장한다.

## 범위

경고 정책/중복 기록, 짧은 합성음, 알림 UI, TopUsageBar·UsagePopup/HTML, TrayApplicationContext,
기존 보기 설정에 소리 옵션, README. 인증·조회 API·설치·자동 시작·GitHub 공개 설정은 변경하지 않는다.

## 검증

Release 빌드 및 공백 검사. 임계값·누락/실패/만료·여러 한도·단계 상승·초기화/회복·1분 제한·재실행 중복 방지,
설정 호환/저장, WAV 헤더·길이·페이드와 최대 진폭, 네이티브/HTML 경고 표시·무포커스·자동 닫힘과 종료 정리.
실계정 한도를 소진하거나 시험 사이렌을 강제로 재생하지 않고 별도 경고 파일과 예시 데이터로 검증한다.
