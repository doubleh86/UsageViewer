# Codex 사용량 트레이 앱

작성일: 2026-10-30

## 목표와 근거

C# Windows 앱을 실행하면 트레이에 상주하고, 아이콘을 클릭하면 Codex 계정의 사용량을 보여준다.
GitHub 연결은 추후 진행하며 현재는 원격 없는 로컬 Git만 만든다.

- 적용 규약: 저장소의 `AGENTS.md`, `Docs/CodeStyle.md`, `Docs/RepositoryWorkflow.md`, `Docs/GitCommitConvention.md`
- 연동 근거: https://learn.chatgpt.com/docs/app-server 의 stdio 초기화, `account/read`, `account/rateLimits/read`

## 이번 구현 범위

검토 가능한 첫 완성본 한 단계로 구현한다.

- .NET 10 Windows Forms, 외부 NuGet 의존성 없음.
- 트레이 왼쪽 클릭으로 팝업 열기/닫기, 오른쪽 메뉴로 열기·새로고침·종료.
- 계정 플랜, 서버가 반환한 각 사용량 구간의 사용률·남은 비율·초기화 시각 표시.
- 구간 길이는 응답 기준으로 표시하며 5시간·주간 구간을 고정 가정하지 않는다.
- 60초 자동 새로고침, 수동 새로고침, 조회 실패·미로그인·미지원 인증 표시.
- 마지막 성공 값을 보존하되 실패/만료 시 최신 값처럼 표시하지 않는다.
- 설치된 Codex CLI를 자식 프로세스로 실행하고 stdio JSON-RPC로 조회. 로그인 파일은 직접 읽지 않는다.
- 중복 실행 시 기존 팝업 열기, 종료 시 timer·트레이·자식 프로세스 정리, 다중 모니터 작업 영역 안에 팝업 배치.
- 실행 안내와 읽기 전용 진단 모드 제공.

예상 파일: `src/UsageViewer/`의 프로젝트, 진입점, 트레이 컨텍스트, 팝업·사용량 컨트롤,
Codex CLI 탐색·RPC·응답 모델, `README.md`, `.gitignore`, `.editorconfig`, `UsageViewer.slnx`.

## 검증

- 최소 `UsageViewer.csproj` Release 빌드.
- 읽기 전용 진단 모드에서 실제 App Server 초기화와 사용량 조회 확인.
- 가능하면 트레이 앱을 실행해 팝업·새로고침·종료를 확인하고 화면을 검토한다.
- 실계정 이메일·토큰·원본 응답은 기록하지 않는다.

## 팝업 후속 수정 (2026-10-30)

- 목표: 트레이 클릭 모니터의 작업 표시줄에 팝업을 배치하고, 조회 후 높이가 바뀌어도 기준 위치를 유지한다.
- 새로고침 버튼은 부모 크기에 따라 폭이 잘못 계산되는 좌표/Anchor 배치를 Dock 레이아웃으로 바꾼다.
- `account/rateLimits/read`의 크레딧 잔액·무제한·미제공 상태를 파싱하고 팝업에 표시한다. 미제공 값을 0으로 추정하지 않는다.
- 영향 파일: UsagePopup, TrayApplicationContext, UsageSnapshot, UsageResponseParser, 크레딧 카드 및 배치 Helper, Program 진단, README.
- 검증: 최소 Release 빌드, 배치·파서의 경계 조건과 읽기 전용 크레딧 응답 확인. Computer Use와 앱 UI 자동 조작은 하지 않는다.
- 상태: 구현 완료.
- 검증 결과: Release 빌드 경고·오류 0개. 크레딧 소수 잔액·미제공·무제한·잘못된 값·명시적 0·다중 버킷/legacy fallback 6개 계약 확인.
- 배치 검증: 조회 후 높이 변경에도 하단 정렬 유지, 음수 좌표 모니터 및 상/좌/우 작업 표시줄에서 작업 영역 내부 배치 확인.
- 폼을 표시하지 않는 레이아웃 검증으로 새로고침 버튼 영역·중앙 정렬과 크레딧 컨트롤 생성 확인.
- 읽기 전용 실계정 진단 성공: 크레딧 정보와 잔액 필드 모두 제공됨. 잔액 값과 개인정보는 진단에 기록하지 않음.
- Computer Use 및 실제 화면 자동 조작은 수행하지 않음. 실제 트레이 클릭과 표시 위치의 시각 확인은 사용자 확인 필요.

## 오른쪽 아래 고정 (2026-10-30)

- 사용자 요청에 따라 클릭 위치는 모니터 선택에만 사용하고, 팝업은 해당 모니터 작업 영역의 오른쪽 아래에 12 DIP 간격으로 고정한다.
- 크레딧 제목의 기본 검정색 상속을 명시적인 밝은 전경색으로 수정한다.
- 영향 파일: PopupPlacementHelper, UsagePopup 호출부, CreditCard, README.
- 검증: 최소 Release 빌드 및 마우스 위치·높이 변경·음수 좌표 모니터의 구석 배치 계산 확인. Computer Use 없음.
- 완료: Release 빌드 경고·오류 0개, 3개 작업 영역 × 3개 높이의 9가지 구석 정렬 확인. 실제 화면 시각 검증은 수행하지 않음.
