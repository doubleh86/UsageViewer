# Claude 사용량 설정 탭 갱신

2026-11-22

## 원인과 범위

공식 사용량 페이지를 여는 실제 조회에서 같은 최상위 문서의 주소가 `/settings/usage`에서 `/new#settings/usage`로 바뀌었다. 사용량 요청 두 건은 전환 후 시작되어 HTTP 200으로 끝났다. 앱은 전환 시 대기 중인 요청이 없어 이미 `NavigationFailed`로 조회를 끝낸 상태였다.

## 작업과 검증

- 연결 창에서 이 설정 탭으로 전환한 현재 문서에 한해 전환 뒤의 공식 사용량 GET도 받는다. 요청 ID, 프레임, 로더, 응답 주소, 기한, 캐시와 저장 검증을 적용한다.
- 기존의 일반 `/new` 전환은 원래 요청만 기다린다. 다른 탭이나 새 문서에서 발생한 요청으로는 완료할 수 없다.
- Release 빌드와 격리 WebView2로 정상 전환과 이탈을 재현한 뒤 실행본의 자동 갱신과 수신 시각을 확인한다.

## 확인 결과

- Release 빌드 경고·오류 0건. 소스·HTML 검사 38건과 격리 검사 548건을 통과했다. 자동·수동·연결 창에서 설정 탭을 연 뒤 보낸 GET은 한 번만 저장됐다. 다른 탭으로 떠난 뒤 도착한 응답과 사용량 페이지를 거치지 않은 직접 탐색은 기존 캐시를 보존했다.
- 실행 중이던 바탕화면 앱을 백업하고 수정본으로 재시작했다. 기존 연결에서 첫 자동 갱신은 11월 22일 11시 28분 07초에 HTTP 200으로 성공했고, 다음 자동 갱신은 11시 29분 11초에 사용량 캐시를 다시 저장했다(한국 시간).
