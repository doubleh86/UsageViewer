# 상단 자동 숨김 탭과 이동

## 요청과 범위

사용자가 선택한 세 번째 시안 ‘자동 숨김 탭’을 적용한다. 탭은 모니터 작업 영역 위쪽에 붙이고,
탭과 펼친 요약 바를 같은 창으로 구성해 마우스로 함께 이동한다. 드래그 중에는 다른 모니터로도 이동할 수 있고,
놓으면 해당 모니터 위쪽에 붙는다. 기존 상세 팝업과 계정 조회 동작은 유지한다.

- 트레이 우클릭 메뉴: ‘모니터 상단에 표시’, ‘항상 가장 앞에 표시’ 체크 옵션.
- 평소 작은 Usage 탭, 마우스를 올리면 32 DIP 요약 바. 떠난 뒤 잠시 후 접힘.
- 클릭하면 바 바로 아래 상세 팝업. 드래그와 클릭을 이동 임계값으로 구분한다.
- 모니터와 가로 위치, 두 옵션을 기존 보기 설정과 함께 저장한다. 분리된 설정 작성자가 덮어쓰지 않게 한다.
- 선택 모니터가 사라지면 주 모니터로 복구하고 작업 영역 밖으로 나가지 않게 한다.
- 해당 모니터의 테두리 없는 전체화면 창이 전경이면 자동 숨김. 정상 창 순서 옵션과 별개이다.
- 오류·미수신·오래된 값은 숫자 0이나 정상 값으로 표시하지 않는다.
- Computer Use나 실제 사용자 앱 조작은 하지 않는다.

옵션·위치 왕복 저장, 다중 모니터 음수 좌표와 경계 배치, 접힘/펼침·드래그 임계값·팝업 연결 위치,

## 후속 수정: 시안 정렬과 Codex 인증 불일치

- 상단 바의 그립·서체·화살표·전체 테두리를 시안에 맞추고, 펼친 바와 상세 화면을 264 DIP 너비로 연결한다.
  상세 화면을 열면 바의 아래 모서리와 상세 화면 위 모서리를 펴서 떨어진 창처럼 보이지 않게 한다.
  트레이에서 여는 기존 320/280 DIP 보기는 보존한다.
- 실제 진단에서 별도 CLI의 `account/read`는 `apiKey`, 한도 조회는 미지원 인증으로 반환됐다.
  이를 다른 인증의 오분류나 재로그인 문제로 취급하지 않는다. Codex 앱 연결에서 얻은 한도 정보와
  별도 CLI의 현재 인증 상태를 구분한다. 인증 파일·키·계정 설정은 직접 열거나 바꾸지 않는다.
- Windows 자격 증명 저장소는 기존 ChatGPT 로그인을 반환하지 않았다. 공식 proxy 연결도 실패했다.
  오래된 실행 기록의 사용량을 현재 값으로 표시하지 않는다.
- Claude 초기화/갱신과 Codex 조회 순서를 분리해 다른 제공자의 지연이 Codex 조회를 막지 않게 한다.
- 최종 실계정 조회 가능 여부는 수정 빌드와 별도로 재검증한다. 사용자에게 인증 방식을 확인 중이다.
- 사용자는 Codex 앱은 ChatGPT 구독, 다른 앱 하나는 API를 사용한다고 확인했다.
  표시기에서 사용자가 ‘ChatGPT 연결하기’를 누를 때만 공식 `account/login/start`를 호출한다.
  로그인과 갱신은 `%LOCALAPPDATA%/UsageViewer/CodexProfile` 전용 `CODEX_HOME`에서 Codex가 관리한다.
  원래 Codex 홈의 로그인·설정·대화와 다른 앱의 API 인증은 변경하지 않는다. 인증 파일을 직접 읽거나 복사하지 않는다.
  이 프로필의 자식 프로세스에서만 API/워크로드 인증 환경을 제거하고 전용 파일 저장소를 사용한다.
  공식 HTTPS 인증 주소만 기본 브라우저로 열고, 완료 알림 이후 읽기 전용 한도 조회로 확인한다.

## 최종 보기 변경: 요약 바 상시 표시

사용자가 실제 요약 바 화면을 첨부하고 이 상태로 계속 표시하도록 요청했다.
상단 표시가 켜져 있으면 264×32 DIP 요약 바를 유지한다. 마우스를 떠나도 Usage 탭으로 접지 않는다.
접힘 상태·hover 전환·불필요해진 그리기 경로는 제거한다. 다른 창 앞 표시, 전체화면 창에서의 숨김,
드래그 위치 저장과 클릭 시 상세 화면 연결은 기존대로 유지한다. 인증·조회 경로는 변경하지 않는다.

검증: Release 빌드, 마우스 진입/이탈·상세 열기/닫기 후 크기 유지, 기존 옵션과 위치 저장,
드래그와 클릭 구분, 실제 네이티브 요약 바 렌더링. 기존 인증 테스트는 인증 코드가 바뀌지 않아 반복하지 않는다.

결과: Release 빌드 경고·오류 0개, 관련 격리 검증 10개 통과. 상시 요약 바 크기, 마우스 이탈과 상세 닫기 후 유지,
드래그/클릭·모니터 경계·위치 저장·네이티브 렌더링과 종료 정리를 확인했다.
`UsageViewer-v0.1.0-win-x64-persistent-bar-20261030-153226.zip`을 생성해 바탕화면 복사 및 해시 일치를 확인했고,
확인된 이전 UsageViewer만 새 버전으로 교체했다. 인증·개인 설정은 변경하지 않았다.

## 수정: 서비스 탭 전환 중 상세창 닫힘

탭 선택 저장이 일반 PreferencesChanged를 발행해 상단 바의 TopMost까지 다시 적용하는 경로를 확인했다.
이 과정의 내부 활성 창 변경은 상세창의 Deactivate → Hide와 충돌할 수 있다.
탭·함께 보기의 저장에서는 창 옵션을 다시 적용하지 않고, 실제 창 옵션·위치 변경만 전용 이벤트로 알린다.
상단 바와 팝업의 TopMost는 값이 달라질 때만 설정한다. 바깥 클릭·Escape·닫기 동작은 보존한다.

검증: 실제 WebView2 문서의 Codex/Claude 탭·함께 보기 전환에서 창 옵션 이벤트가 발생하지 않고,
상세창과 저장된 선택이 유지되는지 확인한다. 창 옵션과 위치 저장 이벤트는 계속 발생해야 한다.
조회·인증은 변경하지 않고, 별도 프로필·예시 데이터로만 검증한다.

결과: 기존 버전의 실제 문서에서 탭 8회와 보기 4회 변경이 창 옵션 콜백 12회로 이어지는 것을 재현했다.
수정 후 실제 WebView2에서 상단 연결/트레이 두 배치의 탭 선택, 보기 변경, 열린 상태와 설정 저장,
실제 창 옵션·위치 이벤트, 닫기/Escape/외부 비활성화 등 38개 검증을 통과했다.
Release 빌드 경고·오류 0개. `UsageViewer-v0.1.0-win-x64-tab-focus-fix-20261030-155342.zip`을 바탕화면에
복사하고 해시 일치를 확인했으며, 확인된 이전 UsageViewer만 새 버전으로 교체했다.
