# 미니 바 작업 상태 표시

작성일: 2026-11-25

## 확정한 화면

- 모니터 상단의 264×32 DIP 요약 바에 진행 중인 작업 수를 표시한다. 기존 사용량, 그립, 상세 화살표와 서비스별 클릭 영역을 유지한다.
- 기본 `앱별` 보기에서는 각 서비스 사용량 옆에 건수를 붙인다. `전체` 보기에서는 오른쪽에 진행 건수 합계를 표시한다.
- 상세 하단 `상단 작업 수`의 `앱별 / 전체`로 전환하고 기존 보기 설정 저장소에 선택을 저장한다. 전환 후 보고 있던 상세 탭을 유지한다.
- `작업` 탭은 합계와 서비스별 진행·대기 건수를 보여준다. 서비스별 상세에도 작업 상태를 한 줄로 추가한다.
- 사용량 영역을 누르면 해당 서비스 상세를 연다. 전체 건수 배지를 누르면 `작업` 탭을 연다. 상세 내 탭 전환으로 팝업이 닫히지 않게 한다.
- 정상적으로 집계된 0건은 상세에 표시하고 상단 배지는 생략한다. 미연동, 수신 대기, 오래된 상태는 상세에서 구분한다.
- 일부만 연동된 경우 상세 합계에 `연동된 작업 중`이라고 표시한다. 집계가 가능한 서비스가 없으면 숫자 대신 상태를 표시한다. 시안의 Codex 2건·대기 1건과 Claude 1건은 예시다.

## 수집 범위와 기준

- 사용자 작업 세션을 하나씩 센다. 같은 세션의 중복 이벤트나 하위 에이전트는 별도 건수로 세지 않는다. 확인된 승인·입력 대기는 진행 건수에서 빼고 따로 표시한다. 관측할 수 없는 항목을 0으로 채우지 않는다.
- 사용량 새로고침과 작업 상태 수집을 분리한다. 작업 이벤트 누락이나 연결 오류가 사용량, 크레딧, 저잔량 알림에 영향을 주지 않는다.
- Codex는 실제 작업을 소유한 App Server의 `thread/list`와 상태 이벤트를 읽을 수 있는지 먼저 확인한다. 한도 조회에 사용되는 새 stdio 프로세스의 런타임 상태를 데스크톱 작업 상태로 사용하지 않는다. 기존 백엔드를 관찰할 수 없으면 로컬 공식 훅으로 확인 가능한 세션을 범위로 정하고, 시작·종료·중단과 관측 한계를 명시한다.
- Claude는 데스크톱 Code 탭의 로컬 세션에서 공식 훅으로 확인할 수 있는 상태를 연결한다. 일반 Chat, Cowork 및 관측되지 않는 원격 세션은 미연동으로 표시한다. `Stop`만으로 중단을 추적할 수 없으므로 실패, 종료와 사라진 수집원의 처리까지 확인한다.
- 훅 방식이 필요하면 사람이 선택해서 연결할 수 있는 안내와 수집 진입점만 제공한다. 사용자의 Codex·Claude 설정과 실행 중인 앱에는 자동 적용하지 않는다. 수집은 세션 구분에 필요한 식별자와 상태·시간만 사용하고 프롬프트, 대화 본문, 작업 경로, 인증 정보, 원본 이벤트는 기록하지 않는다. 검증은 가짜 입력이나 읽기 전용 상태에 한정한다.

공식 근거는 [Codex App Server](https://learn.chatgpt.com/docs/app-server#track-thread-status-changes), [Codex Hooks](https://learn.chatgpt.com/docs/hooks), [Claude Code Hooks](https://code.claude.com/docs/en/hooks), [Claude Code 데스크톱](https://code.claude.com/docs/en/desktop#install-plugins)을 참고한다.

## 구현과 검증

- 작업 상태 모델과 수집 서비스를 추가한다. `TrayApplicationContext`에서 독립 갱신을 연결하고 `TopUsageBar`, `UsagePopup`, `Popup.html`, 보기 설정 모델·저장소에 화면 및 모드 전환을 연결한다. 사용자가 연결할 수 있는 조건과 지원 범위를 README에 기록한다.
- 별도 오케스트레이터 워크트리에서 이 기능만 구현한다. 로컬 메인에 남은 오늘 시작선과 Claude 모달 갱신 복구 관련 변경을 보존한다. 특히 `TrayApplicationContext.cs`, `UsagePopup.cs`, `Popup.html`, 테스트와 README는 결과 통합 전 현재 로컬 변경과의 겹침을 기록한다.
- 최소 Release 빌드와 `git diff --check`를 수행한다. 격리된 이벤트 입력으로 중복, 병렬 실행, 정상 종료, 취소·실패, 대기 전환, 재시작·연결 끊김 및 미연동을 확인한다.
- 예시 데이터로 264×32 DIP 배치, 0건·여러 자릿수 건수의 폭, 제공자 클릭·합계 클릭·탭 전환, 설정 재시작 복원, 사용량·알림과의 독립성을 확인한다. 데스크톱 실제 연결 및 다중 작업의 육안 확인은 사용자 확인 항목으로 분리한다.
